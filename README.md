# MC_Path_finding

La fonction principale se nomme "pathfinding.py" 

sa jumelle "pathfinding_view.py" permet une visualisation du chemin et du graph généré.  

raytracing est un algorithme original O(n) en valeurs entières comme Bresenham, utilisant le produit vectoriel, mais à la differnce de Bresenham, raytracing.py marque toutes les cases traversées par le segement. Il fera l'objet d'un petit papier sur son fonctionnement. 

les deux tests permettent de démontrer l'utilisation de cet algorithme.
